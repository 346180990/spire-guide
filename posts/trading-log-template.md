交易日志最容易写成流水账："周一买入 A，周三卖出 B，赚了 800 块。" 这种日志除了心理安慰，没有任何用处。

**有用的日志，必须让你在半年后读到它时，能重建当时的决策过程。**

下面是我每周固定填写的模板。

## 一、市场状态（3 个字段）

| 字段 | 记录内容 |
| --- | --- |
| 指数与波动 | 主要指数周涨跌幅、波动率分位数（当前处于历史什么位置） |
| 风格与结构 | 大盘/小盘、价值/成长，本周谁占优；行业涨跌前 3 / 后 3 |
| 成交量能 | 日均成交额相对前 4 周的均值，放大还是萎缩 |

**为什么记这个**：很多"策略失效"其实只是风格切换。没有这一栏，你分不清是模型错了还是市场变了。

## 二、策略执行（4 个字段）

| 字段 | 记录内容 |
| --- | --- |
| 信号清单 | 本周系统给出的全部信号，**包括我没执行的** |
| 实际下单 | 实际成交的标的、方向、价格、数量 |
| 滑点 | (成交价 − 信号价) / 信号价，逐笔记录 |
| 执行偏差 | 未执行 / 延迟执行 / 超量执行的，逐条写明原因 |

**为什么记"没执行的"**：这是整份日志里价值最高的一栏。它会暴露你到底在什么情况下不敢动手——通常是某种特定的市场状态，或者某个特定的亏损记忆。

## 三、损益归因（3 个字段）

| 字段 | 记录内容 |
| --- | --- |
| 已实现盈亏 | 分标的明细，不只记总数 |
| 未实现盈亏 | 周末持仓的浮动盈亏 |
| 归因拆分 | 多少来自方向判断，多少来自运气（个股特异波动），多少来自成本损耗 |

**归因拆分可以偷懒用一句话写**，比如："本周 +2.1%，其中约 1.5% 来自周三的单日跳空，属运气。"

## 四、情绪与身体（2 个字段）

| 字段 | 记录内容 |
| --- | --- |
| 情绪标记 | 本周是否有"手痒""恐慌""报复性交易"的冲动，具体触发点是什么 |
| 身体状态 | 睡眠、运动、有无熬夜看盘 |

**为什么这个必须记**：这两栏看起来和量化无关，但它们是**执行偏差最好的预测变量**。回溯三个月，你大概率会发现"手痒"的日子集中出现在睡眠不足的那几周。

## 五、下周计划（1 个字段）

一句话，要可验证。比如：

> 下周若沪深 300 跌破 20 日线，把总仓位降到 50% 以下。

**必须是"若……则……"的形式**，否则就是空话。

## 格式：保持纯文本

我用的就是 Markdown，一个文件一周，文件名带日期：

```text
posts/trading-log-2026-w39.md
```

好处是可以用 git 管理，能 diff，能全文搜索。**"搜索"这个能力被严重低估了**——当你想确认"我上次遇到这种行情是怎么处理的"，全文搜索比记忆可靠得多。

## 一个填好的样例

```markdown
## 一、市场状态
- 指数与波动：沪深300 -1.2%，波动率处于近 3 年 35% 分位
- 风格与结构：小盘跑赢大盘 1.8%；领涨：有色、机械；领跌：地产、白酒
- 成交量能：日均成交 8,900 亿，较前 4 周均值 +6%

## 二、策略执行
- 信号：7 个（3 买 4 卖）
- 实际下单：6 笔，1 笔未执行（未执行：标的 C 买入信号）
- 滑点：均值 0.11%，最大 0.34%（标的 D，开盘集合竞价）
- 执行偏差：标的 C 因"该股上周刚止损过"而跳过 → 情绪干扰

## 三、损益归因
- 已实现：+0.8%
- 未实现：+0.3%
- 归因：方向贡献 +1.4%，运气 -0.5%，成本损耗 -0.1%

## 四、情绪与身体
- 情绪：周三标的 C 触发买入时出现明显抗拒，属止损后的回避心理
- 身体：本周 3 天睡眠 < 6h，均在工作日

## 五、下周计划
- 若沪深300跌破20日线，总仓位降至50%以下
- 把"跳过信号"单独列一张表跟踪（连续 4 周出现即为系统性问题）
```

## 最后

这份模板的价值不在于填满它，而在于**填不出来的那些格子**。

某一周你发现"执行偏差"写不出原因，"情绪标记"写不出触发点——那通常说明那一周你其实没在按系统做，而是在凭感觉做。
