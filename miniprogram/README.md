# 全天候 · 微信小程序

**一个页面回答三个问题：市场什么状态、该买什么、为什么。**

```
市场状态：A股在近三年区间中部（52%）；美股在年线上方 5.3%；债市近一年 +2.8%

沪深300    1000 元  中性 ×1.00
          · 近三年价格区间位置 52%，处于中部，按基础额投入
          · 参考：距三年高点回撤 -17.6%，近一年 -9.7%

标普500    1000 元  年内上行 ×1.00
          · 现价在 200 日均线上方 5.3%，趋势向上
          · 美股用均线而不用估值分位：回测里 60 组参数下估值择时对美股 0% 有效，不减仓

国债ETF    2000 元  恒定投入 ×1.00
          · 不对债券择时：回测里即使债券年化为 0 或 -2%，组合仍能保持 5.2%~6.0%

黄金ETF    1000 元  恒定投入 ×1.00
          · 黄金是保险不是收益来源：与股票相关性仅 0.01，负责防股债同跌

合计：5000 元
```

## 一、装起来（约 20 分钟）

### 1. 装开发者工具

[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版 Stable Build）

### 2. 导入项目

打开工具 → **导入项目** → 目录选 `D:\project\simplejiaoyi\miniprogram`

AppID 可以选「测试号」先看界面，但**云开发必须用真实 AppID**（测试号不支持），所以要自动抓行情就得先注册一个个人小程序（免费）。

### 3. 开通云开发

工具顶部点 **「云开发」** → 开通 → 创建环境（选免费额度，够个人用）。
开通后到 **云开发控制台 → 设置 → 环境ID**，复制那串 ID。

### 4. 填环境 ID

打开 `miniprogram/app.js`，把 `const CLOUD_ENV = ''` 改成你的环境 ID：

```js
const CLOUD_ENV = 'your-env-id-here';
```

### 5. 部署云函数

在文件树里右键 `cloudfunctions/market` → **上传并部署：云端安装依赖**。

它会自动装 `wx-server-sdk`，不需要本地 `npm install`。

### 6. 跑起来

点 **编译**。首页点「刷新行情」，几秒后就能看到建议。

装到手机上：点「预览」扫码（临时），或「上传」→ 小程序后台设为**体验版**（永久，不需审核，体验成员上限 15 人）。

## 二、为什么必须用云函数

微信小程序的 `wx.request` **只能请求你在后台配置过的、有 ICP 备案的自有域名**。东财、腾讯的行情接口配不进去，真机上会被拦截。

云函数跑在服务端，出网不受这个限制 —— 这是小程序抓外部数据唯一可行且免费的路子。

**双源互备**：主用腾讯 `web.ifzq.gtimg.cn`，失败自动切东财 `push2his`。这不是过度设计——实测东财的历史 K 线接口会因为频繁调用被限流（`socket hang up`），单源必挂。

## 三、推荐规则怎么来的

全部来自本地真实回测（2013-07 ~ 2026-10，真实国债ETF 511010 + 黄金ETF 518880，含分红再投资）。详细推导见仓库根目录 `README.md`。

### 四条硬规则

| 规则 | 依据 |
|---|---|
| **每月总投入不变**，只调内部配比 | 你的现金流要稳定，不能这个月 5000 下个月 8500 |
| **信号只做 ±15% 微调**，不押注 | 回测：分散能 +5.5pt，择时中位只有 +1.2~1.7pt 且会失效 |
| **按市场选不同信号** | A股看价格区间位置；美股看 200 日均线；债券黄金不择时 |
| **优先用新钱再平衡**，不卖出 | 零交易成本，不打断复利 |

### 为什么 A股 和美股用不同信号

- **A股**：用「近三年价格区间位置」（估值分位的价格代理）。A股 波动大、均值回归明显，区间位置有参考价值。
- **美股**：用「距 200 日均线」。回测里 60 组参数扫描，**估值/位置择时对美股 0% 能跑赢普通定投**——因为美股长期高于自身滚动均值，一择时就一直踏空。趋势跟随才对。

### 为什么债券和黄金不择时

- **债**：回测显示即使债券年化为 0（-1.3pt）或 -2%（-2.1pt），组合仍能保持 5.2%~6.0%。为这点波动去择时得不偿失。
- **金**：它是保险不是收益来源。与股票相关性仅 0.01，是组合里唯二真正的对冲（另一个是债券）。保险不该择时。

## 六、局限（写在设置页里，不藏）

- 回测不能预测未来。2013-2026 中国国债几乎年年正收益，这段「完美对冲」有时代红利。
- A股只有 21.8 年历史，样本短，别把历史规律当物理定律。
- **历史 PE/PB 序列拿不到**，所以"估值分位"用价格区间位置代理，**不是真正的估值**。
- 未计汇率、QDII 溢价与申赎费；境外指数按本币计价。
- **不构成投资建议。**

## 七、云开发排查清单

### 三个 ID 别搞混

| 名称 | 长什么样 | 填到哪 |
|---|---|---|
| **AppID** | `wx8e9cf1fe64c553e6`（`wx` + 16 位） | `project.config.json` 的 `appid`（**已填好**） |
| **云开发环境 ID** | `prod-8gx3k2`（字母 + 短横线，绝不会是纯数字） | `app.js` 的 `CLOUD_ENV`。**只有一个环境时留空即可** |
| 腾讯云账号 ID | `100021790435`（纯数字） | 哪里都不用填 |

环境 ID 留空的原理：`wx.cloud.init({ env: undefined })` 在账号下只有**一个**环境时会自动使用默认环境。
只有建了多个环境（测试/生产）才必须显式指定。

### 常见报错

| 现象 | 原因 | 解决 |
|---|---|---|
| 工具栏找不到「云开发」 | 微信号不是该小程序的开发者 | [小程序后台](https://mp.weixin.qq.com) → 成员管理 → 添加微信号 |
| 右键 `cloudfunctions` 没有「上传并部署」 | 云开发环境还没创建 | 先点顶部云图标创建环境，等创建完成 |
| 报「云开发还没开通，或当前微信号不是该小程序的开发者」 | 同上 | 同上 |
| 报「云函数调用失败」/ `FunctionName not found` | 云函数没部署成功 | 重新上传部署，看控制台输出 |
| **一直「更新中…」或超时** | **云函数默认超时 3 秒不够**（要抓 4 个标的 + 冷启动） | 云开发控制台 → 云函数 → market → 配置 → **超时时间改 10 秒** |
| 报「两个数据源都没拿到足够数据」 | 腾讯和东财都失败 | 云开发控制台 → 云函数 → market → 日志，查看具体错误 |
| 报错但 AppID 明明是新的 | 工具还在用旧 AppID | 移除项目 → 重新导入 `miniprogram` 目录 |

### 云函数部署要点

- 必须选 **「上传并部署：云端安装依赖」**，不要选「所有文件」——后者需要你本地先 `npm install`
- 部署成功后在云开发控制台 → 云函数，能看到 `market` 且状态正常
- 改动 `cloudfunctions/market/index.js` 后**必须重新上传部署**才生效（小程序端的改动只要编译）
- 改动 `core/recommend.js`（推荐规则）**不需要**重新部署云函数，编译即可

### 费用提醒

微信云开发新环境一般是限时免费试用，之后转付费套餐。**创建环境页面上会显示价格，确认前看清楚。**

如果不想付费，有两条替代路：

1. **手动填数据**：把 `core/api.js` 的 `fetchMarket` 改成返回手工填的 JSON，每月更新一次
2. **鸿蒙原生版**：`harmony/` 目录，鸿蒙联网没有域名白名单限制，零服务器成本，但需要签名安装
