# Spire Atmosphere

**Status:** proposed

The site background SHALL evoke the Slay the Spire 2 dungeon atmosphere using CSS-only techniques.

### Requirements

- **B1.** Body background SHALL include a stronger top-down torchlight glow (warm gold, more visible than current 0.06 opacity)
- **B2.** Body background SHALL include a pronounced bottom darkness gradient (deep abyss feel)
- **B3.** Body background SHALL include a vignette effect (darker edges, lighter center)
- **B4.** The existing SVG noise texture overlay SHALL be preserved
- **B5.** No external image assets SHALL be required — pure CSS gradients
- **B6.** All text MUST remain readable (contrast ratio maintained)

### Acceptance

- Background has a distinct "looking up at the Spire" feel — torchlight above, darkness below
- Readability is not compromised
- No new image files or external URLs added
