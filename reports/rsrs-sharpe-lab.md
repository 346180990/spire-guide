# RSRS 夏普实验室：哪些改动真能提高夏普/收益

> 数据：沪深300 日线 2005-01-04 → 2026-10-23（5294 根）
> 口径：T 日收盘出信号、赚 T+1 收益；单边成本 10bp；rf=3%；年化 244 日
> 复现：`node scripts/rsrs-sharpe-lab.mjs`（加 `--weekly` 看周线）、`node scripts/rsrs-defensive-lab.mjs`
> 明细：`reports/rsrs-sharpe-lab.json`

## 一句话结论

**RSRS 的信号本身没什么可再挖的了；夏普的提升来自「怎么退出」和「空仓时拿什么」，不是来自换指标或调参数。**

- 现有实现在全样本上是 **夏普 0.55 / 年化 11.4% / 回撤 54.6%**。
- 加「MA20 上倾 + 8% 移动止损 + 止损后冷却 5 日」→ **0.76 / 12.2% / 18.9%**（空仓按 rf 记账则 0.94）。
- 把空仓的现金换成短债/货基（≈rf），同一策略夏普再 **+0.15~0.19**——这是记账口径，不是新 alpha。
- **2017 年后按「空仓=现金」口径没有任何一组参数能做出稳定正夏普**（推荐配置 2017-2021 为 0.33，2022-2026 为 −0.32）；改按 rf 记账会回到 0.24~0.38，但那部分是空仓生息，不是择时 alpha。

---

## 方法：为什么敢下这个结论

单条净值曲线很容易骗人，所以做了三件事：

1. **机制 × 参数网格**：每个候选改动（机制）在 3 个指标 × M{120,250,300,600} × S{0.7,0.9} = 24 组参数上各跑一遍，用**族中位数**排名，而不是挑最好的那一组。
2. **同参数配对**：同一组参数下，改动版 vs 无过滤版逐对比较，看胜率，而不是看绝对收益。
3. **分期检验**：2006-2011 / 2012-2016 / 2017-2021 / 2022-2026 分开算，识别「只在 2008 有效」的假改进。

## 一、有效的改动（按贡献排序）

| 机制 | 夏普（族中位数） | 同参数胜率 | 夏普提升 | 回撤 | 年化 |
|---|---|---|---|---|---|
| 无过滤（基线） | 0.43 | — | — | 53.8% | 9.6% |
| **MA20 上倾过滤** | 0.63 | 24/24 | +0.17 | 21.8% | 10.7% |
| **+ 8% 移动止损** | 0.68 | 24/24 | +0.22 | 21.9% | 11.2% |
| **+ 止损后冷却 5 日** | 0.65 | 24/24 | +0.21 | 21.8% | 11.1% |
| **三层叠加** | **0.68** | **24/24** | **+0.22** | **20.3%** | **10.9%** |
| 连亏后减半（60 日≥2 次止损） | 0.70 | 24/24 | +0.19 | 18.0% | 10.6% |
| ATR(3×) 止损替代固定 8% | 0.64 | 24/24 | +0.17 | 23.3% | 10.8% |
| 波动分位 >0.8 禁开新仓 | 0.55 | 24/24 | +0.13 | 23.3% | 9.1% |
| 只在 MA200 上方做多 | 0.58 | 19/24 | +0.08 | 28.0% | 9.5% |
| MA20 上倾 + MA200 | 0.57 | 23/24 | +0.11 | 19.4% | 8.8% |
| 目标波动 15% | 0.51 | 18/24 | +0.06 | 17.9% | 7.5% |
| 3 日 z 中位数 | 0.50 | 19/24 | +0.05 | 21.0% | 9.1% |

**具体到线上参数**（修正标准分 18/300/0.7）：

| 版本 | 年化 | 夏普 | 回撤 | 卡玛 | 2017 后夏普 |
|---|---|---|---|---|---|
| 现状（无过滤） | 11.4% | 0.55 | 54.6% | 0.21 | ≈0 |
| + MA20 上倾 | 11.6% | 0.68 | 21.8% | 0.53 | −0.03 |
| + MA20 + 止损 8% + 冷却 5 日 | 12.2% | 0.76 | 18.9% | 0.65 | +0.02 |
| 同上，S 改 0.9 | 12.5% | 0.82 | 18.2% | 0.68 | +0.06 |
| 同上，空仓按 rf 记账（S=0.7） | 14.7% | 0.94 | 17.1% | 0.86 | +0.24 |
| 同上，空仓按 rf 记账（S=0.9） | 15.1% | **1.01** | 17.1% | 0.88 | +0.30 |

为什么是这三层：

- **MA20 上倾**：RSRS 是右侧趋势信号，顶部退出很慢；均线斜率提供一个更快的「趋势已坏」出口。24 组参数全部改善，是整套改动里最稳的一层。
- **8% 移动止损**：把单次判断错误的代价封顶（2008、2015 这种单边下跌），同时不改变上涨段的持仓。
- **止损后冷却 5 日**：刚被止损说明信号在震荡市里失效，立刻原价买回去等于给券商送钱；冷却一周把「同一段假信号反复进出」掐掉。换手从 8.7 降到 8.0 次/年。

「连亏后减半」的族中位数（0.70）比三层叠加还高 0.02，但它多一层状态、2017 后并不更好（−0.05），不值得为 0.02 增加维护成本。

## 二、看着合理、实测无效（甚至有害）的改动

| 改动 | 结果 | 原因 |
|---|---|---|
| **跌破 MA20 就离场** | 夏普 0.13，胜率 0/24，年化 −5.6pt | 把慢信号变成高频信号：换手 **55 次/年**，10bp×55 ≈ 每年 5.5% 成本，正好等于少掉的收益 |
| 跌破 MA60 离场 | 夏普 0.23，胜率 0/24 | 同上，换手 51 次/年 |
| 2 日 / 3 日确认才入场 | 夏普 0.06 / 0.00，年化跌到 3.1% / 2.6%，胜率 0/24 | 确认期错过反弹第一段，A 股收益高度集中在少数几天；等确认完，肉已经没了 |
| 周线 RSRS | 夏普 0.31（日线 0.55） | 降频没减少假信号，只是把反应变慢 |
| MA10 上倾 | 夏普 0.39，胜率 3/24 | 太快，等于噪音 |
| 只在 MA200 上方 | 夏普 +0.08，但 2017 后 −0.06 | 熊市反弹全错过，且 200 日太慢 |
| 目标波动 15% | 夏普 0.51（没升），换手翻倍到 16 次/年 | 波动率目标只改变仓位尺度，不改变信号质量；夏普理论上不变 |
| 极端 z（>2.5）降半仓 | 夏普 −0.02 | 强趋势里 z 高是好事，不是泡沫信号 |
| 入场需 z 上行 | 夏普 ±0.00 | 与状态机本身重复 |
| 按 z 分档加仓 | 夏普 0.35，年化 6.3%，换手 13.9 次/年 | 仓位跟着 z 抖，收益没多拿、成本先付了 |
| 仅 8% 止损（不加 MA20） | 夏普 0.44，胜率 7/24 | 止损不能替代趋势过滤，只能叠加 |

**一句话**：所有「让信号更敏感」的改动都在亏钱，所有「让退出更果断 + 少交易」的改动都在赚钱。

## 三、被低估的 0.15~0.19：夏普的记账口径

`core/metrics.js` 里 `sharpe = (日均收益 − rf/244) / 日波动 × √244`，但回测里**空仓的现金收益是 0**。等于假设「空仓还倒贴 3% 无风险利率」。

| 策略 | 现金口径 | 空仓按 rf 记 | 差 |
|---|---|---|---|
| 修正 + MA20 上倾 S=0.7 | 0.68 | 0.85 | +0.17 |
| 修正 + MA20 上倾 S=0.9 | 0.77 | 0.96 | +0.19 |
| 右偏 + MA20 上倾 S=0.7 | 0.72 | 0.87 | +0.15 |
| 右偏 + MA20 上倾 S=0.9 | 0.78 | 0.94 | +0.16 |

这不是策略变好，是记账。两种处理都合理，但**必须选一个并说清楚**：

- 若认为空仓就是券商现金（0 收益）→ 现在的算法没错，但 rf 应该用真实活期/逆回购利率（2024-2026 约 1.5%），而不是 3%。
- 若认为空仓可以买货基/短债 → 回测里就该给空仓记 rf，否则夏普系统性偏低约 0.15。

建议：**夏普同时报 rf=0 / 1.5% / 3% 三档**，或者把「空仓收益率」做成配置项。当前 Web 里 2018-2026 那些 −0.07 的夏普，用 rf 口径会回到 +0.05 附近——数字难看有一半是口径造成的。

## 四、参数：M=600 太长，N=20 会崩

推荐配置下的参数邻域（夏普）：

| N \ (M,S) | 250/0.7 | 250/0.9 | 300/0.7 | 300/0.9 |
|---|---|---|---|---|
| 16 | 0.68 | 0.72 | 0.74 | 0.76 |
| **18** | **0.77** | **0.77** | **0.76** | **0.82** |
| 20 | 0.51 | 0.50 | 0.51 | 0.57 |

- **N=18 是平台**（16 也还行），N=20 直接掉到 0.5 且 2017 后转负——不是「更稳」，是信号变钝。
- **M=250~300（1~1.2 年）优于 M=600**：600 日标准化在 A 股这种风格切换快的市场里太慢。
- S=0.7 与 0.9 差别不大（0.76 vs 0.82），S=0.9 略好但样本内优势不足以当结论。

**别把「M=250 更好」当成新发现**：这是同一机制的参数平台，换一段样本顺序可能就翻过来。真正稳的是机制（趋势过滤 + 止损 + 冷却），不是具体数字。

## 五、残酷事实：2017 年后没有 alpha

推荐配置（修正 18/300/0.7 + 三层过滤，**空仓=现金 0 收益**）分期：

| 区间 | 年化 | 夏普 | 回撤 |
|---|---|---|---|
| 2006-2011 | 26.2% | **1.35** | 15.4% |
| 2012-2016 | 16.5% | **1.11** | 14.1% |
| 2017-2021 | 5.9% | 0.33 | 12.6% |
| 2022-2026 | −0.5% | **−0.32** | 18.2% |

若把空仓改记 rf（3%），同样这两段会变成 2017 后 +0.24、2019 后 +0.28——看起来好看了，但拆开看仍然是「空仓那部分在生息」，不是择时在赚钱：2022-2026 指数年化约 −1%，策略空仓拿 3%，当然跑赢现金。

逐年看也一样：跑赢买入持有的年份 12/21，但 2019 年之后基本是「少亏」而不是「多赚」。

这说明：**全样本夏普从 0.55 抬到 0.76，主要来自 2008 和 2015 两次成功空仓**。把这两段拿掉，RSRS 择时在最近五年是零贡献到负贡献。这不是参数问题——24 组参数里 2017 后为正的只有 15 组，且中位数只有 0.06。

## 六、要收益更高：空仓别拿现金，拿一个会涨的东西

同样的 RSRS 信号（修正 18/300/0.7 + 三层过滤），空仓腿换成本地有真实数据的黄金 ETF（518880，2013-07 起）：

| 策略（2013-07 → 2026-10） | 年化 | 波动 | 夏普 | 回撤 | 2017 后夏普 | 2022 后夏普 |
|---|---|---|---|---|---|---|
| 沪深300 买入持有 | 4.9% | 20.9% | 0.19 | 46.7% | 0.05 | −0.30 |
| 黄金 ETF 买入持有 | 9.0% | 15.0% | 0.45 | 31.3% | 0.65 | 0.90 |
| RSRS（空仓现金） | 6.6% | 10.5% | 0.38 | 18.9% | 0.02 | −0.32 |
| **RSRS（空仓黄金）** | **14.9%** | 16.3% | **0.75** | 22.4% | 0.72 | 0.91 |

机制很清楚：**组合夏普 ≈ 各腿夏普的加权**。现金的夏普是 0（甚至 −rf），把它换成一个正夏普资产，组合夏普立刻上一个台阶；RSRS 的作用从「创造收益」退回到「决定何时坐哪条腿」。

必须泼冷水：2013-2026 黄金是一段大牛市，这个 14.9%/0.75 **不能外推**。换成 3%/年、2.5% 波动的国债，夏普提升会小得多（约 +0.1）。但这个方向是对的——README 里「分散 >>> 择时」的结论，在这里同样成立。

## 七、推荐落地配置

```text
指标：修正标准分RSRS（或 右偏修正标准分RSRS）
参数：N=18, M=300, S=0.9（保守用 S=0.7）
过滤：MA20 上倾（T-1 > T-3）
退出：从持仓最高收盘回撤 8% 离场
冷却：离场后 5 个交易日不再入场
空仓腿：货基/短债（≈1.5~3%），不要留 0 收益现金
```

预期（沪深300 全样本，10bp 成本）：**年化 12.5%、夏普 0.82、最大回撤 18.2%**；空仓按 rf 记账则年化 15.1%、夏普 1.01、回撤 17.1%。但 2017 年后按现金口径只有 0.05~0.2（按 rf 口径 0.24~0.30，且主要是空仓生息），别期待它单独扛住未来。

成本敏感性：5/10/20/30bp 对应夏普 0.79/0.76/0.69/0.62——不脆，但也不是免费。

### 接入现有代码的做法

`core/rsrs.js` 加一个纯函数（不改变现有导出行为）：

```js
/** 退出规则：移动止损 + 冷却期。pos 为 0/1，closes 为收盘价 */
function applyExitRules(pos, closes, opts) {
  const dd = (opts && opts.stopLoss) || 0;
  const cool = (opts && opts.cooldown) || 0;
  const out = new Array(pos.length).fill(0);
  let hold = 0, peak = -Infinity, wait = 0;
  for (let i = 0; i < pos.length; i++) {
    if (wait > 0) { wait--; out[i] = 0; continue; }
    if (!hold) {
      if (pos[i] === 1) { hold = 1; peak = closes[i]; }
    } else {
      if (closes[i] > peak) peak = closes[i];
      if (dd > 0 && closes[i] / peak - 1 < -dd) { hold = 0; wait = cool; }
      else if (pos[i] === 0) { hold = 0; wait = cool; }
    }
    out[i] = hold;
  }
  return out;
}
```

接入点：

1. `core/signal.js` 在 `applyTrendFilter` 之后调用；参数从 `p.stopLoss` / `p.cooldown` 读。
2. `core/backtest.js` 同样位置调用，保证回测与信号一致。
3. `core/catalog.js` 的 preset 加 `stopLoss: 0.08, cooldown: 5`。
4. `web/` 的参数面板与 `web/lib/jobs.mjs` 透传这两个字段。
5. `miniprogram/core/` 是副本，改完跑 `node scripts/sync-to-ide.mjs`。
6. `scripts/check-strategy.mjs` 的黄金值会变，需要同步更新；建议新增一个「无退出规则时与旧版逐位一致」的断言，保证向后兼容。

## 八、局限（必须写在结论旁边）

1. **单指数、单市场**：只有沪深300 全历史在本机；创业板/中证500/标普500 这次没联网验证。README 里已有的结论是标普500 全程负贡献。
2. **21 年只有两次大熊市**：MA20 + 止损的价值高度依赖 2008/2015，样本外可能显著缩水。
3. **参数平台不等于安全**：N=16~18、M=250~300 都行，但这是同一段历史里的平台。
4. **未计**：ETF 跟踪误差、T+1 执行偏差、大额冲击成本、分红（价格指数）。
5. **与 README 里引擎复算的数字略有差异**（例如「修正 + MA20」这里 0.68、README 引擎口径 0.64）：
   本实验室用「回归窗口含当日」的自然对齐 + 10bp 成本，引擎用 notebook 对齐 + 8bp；
   方向与结论一致，不需要对齐到小数点后两位。
6. **黄金/债券那条腿是资产配置，不是 RSRS**：把它的收益算进「RSRS 优化」会高估 RSRS 本身。
7. 不构成投资建议。

## 附：做与不做的清单

**值得做**
- 加 MA20 上倾过滤（如果线上还没默认开）
- 加 8% 移动止损（或 3×ATR）
- 加止损后 5 日冷却
- 空仓收益按真实货基/短债记账，或至少同时报 rf=0/1.5/3%
- 空仓腿配置短债/货基，而不是 0 收益现金

**不值得做**
- 换更多指标版本（六个版本已横评过，标准分/修正最好）
- 加确认期、周线、MA10、跌破均线离场、分档加仓、波动率目标
- 继续在 M/N/S 上搜「最优参数」
- 指望 RSRS 单独在 2022-2026 这种市场里做出正夏普
